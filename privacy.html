Privacy policy

Last updated: 5 October 2026.

Who uses this app. AIOS Associé is a personal tool used only by its owner, with the owner's own Google account. No other user is accepted.

Data accessed. With the owner's consent, the app requests read-only access to Google Calendar (calendar.readonly) and Gmail (gmail.readonly). It reads upcoming calendar events and the sender, subject and date of recent emails. It does not read email bodies or attachments, and it never sends, modifies or deletes anything.

Processing and storage. Data is processed locally on the owner's computer to build a short daily summary for the owner. Google data is not sold, shared, transferred to third parties or used for advertising. The OAuth token is stored only on the owner's computer.

Limited Use. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

Contact. Through the GitHub account that hosts this site.
